# M16b — Speaker Output in Simulated Mode (v0.3.1)

**Status:** released  
**Version:** 0.3.1  
**Goal:** Route the effect's output to the system speakers in Sine and WAV modes so the user can hear the processed audio without requiring a microphone.

---

## Context

In v2, audio output to speakers only works when the "Live (mic)" input is selected, because that mode opens a full-duplex CoreAudio AUHAL device. Sine and WAV modes run `run_simulated()`, which computes audio but discards the output buffer — it only sends scope/FFT data over IPC. The user cannot hear any sound in the default Sine mode.

No OS config change is needed. The fix is entirely in the emulator runtime C++ code.

## Tasks

- [x] T16b-1 — Add output-only CoreAudio support to `CoreAudioDevice`
- [x] T16b-2 — Drive `run_simulated()` from the CoreAudio render callback

### T16b-1 — Add output-only CoreAudio support

**Files:** `emulator/runtime/core_audio_device.h`, `emulator/runtime/core_audio_device.cpp`

**DoD:**
- `CoreAudioDevice` gains a `start_output_only(sampleRate, bufferSize, ProcessFn)` method.
- Internally it opens an AUHAL output-only device: enables bus 0 (output), does NOT enable bus 1 (input), does NOT allocate `inputBufList`, does NOT call `AudioUnitRender`.
- The `ProcessFn` receives a zeroed stereo-interleaved input buffer and a stereo-interleaved output buffer to fill.
- Existing `start()` (duplex) is unchanged.

### T16b-2 — Drive `run_simulated()` from the CoreAudio render callback

**Files:** `emulator/runtime/audio_engine.cpp`

**DoD:**
- `run_simulated()` opens a `CoreAudioDevice` in output-only mode.
- All audio generation (sine / WAV / replay), effect invocation, volume scaling, scope accumulation, and FFT emission happen inside the CoreAudio render callback.
- The `sleep_for(block_ns())` timing loop is replaced by CoreAudio-driven timing.
- If `start_output_only()` fails (no output device), the engine falls back to the old silent software loop (prints a warning to stderr).
- No regression to `run_realtime()` (Live mic mode).
