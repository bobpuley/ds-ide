# M15 — Scope UI refresh

**Status:** in progress
**Target version:** 0.2.9
**Goal:** Reorganise the scope webview (C2) for clarity and usability — cleaner separation
between emulator controls and effect controls, context-sensitive emulator bar, and a persistent
master output volume knob.

**DoD → AC-17 green** (all scope UI tasks demonstrably improved per AC below); no regression to
AC-1…AC-16. Sprint-close → CHANGELOG + 0.2.9 tag.

---

## Tasks

- [x] T15.1 — **Input source selector → dropdown** *(FR-AU-7)*: replace the three radio buttons
  with a single `<select>` dropdown. Same three options (Sine / Live (mic) / WAV).
- [x] T15.2 — **Collapsible footer sections**: split the flat footer into two collapsible
  sections — *Effect controls* (pots, buttons, LEDs — expanded by default) and *Emulator*
  (emulator bar — collapsed by default). Each section header is a clickable toggle (▾/▸).
  Canvas resizes correctly on both collapse and expand (`ResizeObserver` + `min-height: 0`).
- [x] T15.3 — **Context-sensitive emulator bar** *(FR-AU-9 refined)*: collapse all emulator
  rows into a single inline bar; show only controls relevant to the active input source:

  | Control          | Sine | Live | WAV |
  |------------------|:----:|:----:|:---:|
  | Freq + Amp       | ✓    |      |     |
  | Choose WAV + Loop|      |      | ✓   |
  | Buffer           |      | ✓    | ✓   |
  | Latency          |      | ✓    |     |
  | Xruns            |      | ✓    | ✓   |

  Recording controls (Record / Stop / Replay) remain always visible in the emulator bar,
  separated by a stronger visual divider.
- [x] T15.4 — **Master output volume** *(FR-AU-10)*: add a `Vol` slider to the scope header,
  always visible regardless of input source or section state. Sends `outputVolume` IPC message;
  emulator scales the output buffer before writing to CoreAudio.
- [ ] T15.5 — **Validation**: manual test across all three input sources; verify canvas resize
  on collapse/expand; verify output volume audibly affects speaker level.
