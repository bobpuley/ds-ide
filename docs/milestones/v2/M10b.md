# M10b — Visual controller editor

**Status:** in progress
**Target version:** 0.2.3
**Goal:** Drag controls onto a canvas, wire each to a Daisy pin, and have `controllers.yaml`
updated automatically — so the layout doubles as a hardware wiring reference.

**DoD → AC-15 green** (visual editor round-trip: load yaml → render → edit → save yaml); no
regression to AC-1…AC-11. Sprint-close → CHANGELOG + 0.2.3 tag.

> Depends on M10: the yaml schema and controller panel must exist first.

---

## Tasks

- [x] T10b.1 — **Editor canvas** (C2): new tab alongside scope/controller panel — drag controls
  from a palette (pot, button, LED) onto a free-form panel.
- [x] T10b.2 — **Pin wiring UI** (C2): each placed control exposes an ADC channel (pots) or GPIO
  pin (buttons/LEDs) selector; selected value written to yaml.
- [x] T10b.3 — **YAML round-trip** (C2): load → parse → render onto canvas; save → serialize
  canvas state → write yaml.
- [x] T10b.4 — **Palette sidebar** (C2): available control types listed; drag-to-canvas to
  instantiate.

> No new IPC messages required — the runtime reads yaml on deploy; the editor only edits the file.
