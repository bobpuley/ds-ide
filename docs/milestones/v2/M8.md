# M8 — Real-time audio I/O

**Status:** in progress
**Target version:** 0.2.0
**Goal:** Play live audio through an effect and hear the output through the host speakers in real time.

**DoD → AC-9 green** (live host input → effect → host speaker output, audible in real time); no
regression to AC-1…AC-8 (simulated sine mode still works). Sprint-close → CHANGELOG + 0.2.0 tag.

> **macOS note:** CoreAudio requires VS Code (the host process) to have microphone permission.
> macOS will prompt on first use. If denied, `audioMode: realtime` will fail to open the input
> device and the runtime will log an error and fall back to simulated mode.
