# M10 — Virtual buttons, GPIO & LEDs

**Status:** needs review
**Target version:** 0.2.2
**Goal:** Press a virtual button and have the effect respond; trigger an LED from the effect and
see it lit in the UI.

**DoD → AC-11 green** (virtual button press reaches the effect; effect-driven LED lights in the UI);
no regression to AC-1…AC-10. Sprint-close → CHANGELOG + 0.2.2 tag.

> ⚠️ Scope must be reviewed and locked before implementation. The tasks below are a starting
> sketch only — minimal controls (buttons) and minimal outputs (LEDs) confirmed; exact
> IDs and yaml schema details to be finalized in the pre-implementation review.
