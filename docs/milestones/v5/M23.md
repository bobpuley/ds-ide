# M23 — Effect Project Wizard

**Target version:** 0.5.0
**Status:** in progress
**Closes:** AC-36
**Decisions:** D22 (wizard command scaffolds new effect project)

---

## Goal

A developer starting from scratch should be able to bootstrap a ds-ide-ready effect project
in under a minute, without manually writing boilerplate or understanding the convention syntax.
`ds-ide: Create New Effect Project` handles the setup.

---

## Tasks

### T23-1 — Implement `ds-ide: Create New Effect Project` command ✅

- Register command `ds-ide.createNewEffectProject` in `package.json` and C1.
- Prompt flow:
  1. `vscode.window.showInputBox({ prompt: "Effect project name", validateInput })` — validates
     non-empty, valid C++ identifier (alphanumeric + underscore, not starting with digit).
  2. `vscode.window.showOpenDialog({ canSelectFolders: true, openLabel: "Create here" })` —
     destination folder picker.
- Scaffold the following in `<destination>/<name>/`:

  **`<name>.cpp`**
  ```cpp
  #include "daisy_seed.h"
  #include "daisysp.h"

  using namespace daisy;
  using namespace daisysp;

  DaisySeed hardware;

  // ds-ide:controls:begin
  // Add controls here using the Wiring Editor (ds-ide: Open Wiring Editor)
  // ds-ide:controls:end

  void AudioCallback(AudioHandle::InputBuffer in,
                     AudioHandle::OutputBuffer out,
                     size_t size) {
      for (size_t i = 0; i < size; i++) {
          out[0][i] = in[0][i];
          out[1][i] = in[1][i];
      }
  }

  int main() {
      hardware.Init();
      hardware.StartAudio(AudioCallback);
      while (true) {}
  }
  ```

  **`CMakeLists.txt`** — pre-configured for the ds-ide emulator build (match existing
  project conventions; use the same structure as existing example projects in the repo).

  **`controllers.yaml`**
  ```yaml
  controls: []
  ```

  **`README.md`** — brief instructions: how to open in ds-ide, how to add controls via
  the Wiring Editor, how to build and run.

- Write files via `vscode.workspace.fs.writeFile()`.
- After writing: `vscode.commands.executeCommand('vscode.openFolder', uri, { forceNewWindow: false })`.
- On any error (folder exists, write failure): surface via `vscode.window.showErrorMessage`.

**DoD:**
- Running the command on a fresh VS Code window prompts for name + folder.
- All four files are created with correct content.
- VS Code opens the new project folder.
- An invalid name (empty, spaces, starts with digit) is rejected inline with a clear error.
- AC-36 passes.

## Notes

- C1-only change. No new components, no IPC changes, no architecture impact.
- `CMakeLists.txt` template content should be derived from the existing project structure at
  implementation time — do not hard-code paths that may change.
- The empty `// ds-ide:controls:begin/end` block is valid for C9 and FR-CE-6 (no controls
  detected → yaml-only fallback until controls are added via Wiring Editor).
