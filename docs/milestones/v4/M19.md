# M19 — UX Polish & Command Improvements (v0.4.0)

**Status:** planned
**Version:** 0.4.0
**Depends on:** M18 (released — no active blockers)
**Goal:** Ship a set of independent, small UX improvements across the command surface, Scope view, and Wiring Editor. No architecture changes.

---

## Context

All v3 milestones are released (M16–M18, 0.3.3). This milestone addresses UX friction points identified in the post-v3 review (`to_check.md`, 2026-06-20). Each task is self-contained; all can be parallelised.

---

## Tasks

### T19-1 — Add "Build & Deploy to Emulator" combined command

Implement `ds-ide.buildAndDeployToEmulator` command in C1 that:
- Runs the build-for-emulator step
- If build succeeds: runs deploy-to-emulator
- If build fails: surfaces an error in the Output panel; deployment does not proceed
- Registers the command in the VS Code command palette as "Daisy IDE: Build & Deploy to Emulator"

**DoD:** AC-26 passes. Command appears in palette. Error case is tested: build failure stops before deploy.

---

### T19-2 — Stop/Start Audio toolbar buttons in Scope view header

Add Stop Audio and Start Audio icon buttons to the Scope view (C2) header toolbar:
- Start Audio is disabled while the emulator is running
- Stop Audio is disabled while the emulator is stopped
- Buttons use the same underlying commands as the palette equivalents
- Buttons must not duplicate or replace the existing palette commands

**DoD:** AC-27 passes. Buttons are visible in the Scope header. State reflects emulator running/stopped.

---

### T19-3 — Simplify session recording button labels

In C2, update the recording button labels:
- "() Record" → "()"
- "[] Stop" → "[]"
- "> Replay file…" — no change

**DoD:** AC-28 passes. Labels updated. No functional change to recording behaviour.

---

### T19-4 — Fix Wiring Editor ID label visibility

In the Wiring Editor SVG (C10), reposition the ID label of each assigned control so it:
- Does not overlap the control icon or pin circle
- Is vertically centred on the pin row
- Is positioned between the control icon and the Daisy Seed diagram body (right-shifted from current)

Reference: screenshot `to_check_screenshot_1.png`.

**DoD:** AC-29 passes. At least two assigned controls visible simultaneously without label overlap.

---

### T19-5 — Add micro USB port indicator to Daisy Seed SVG

In the SVG asset (C10 webview), add a micro USB port shape at the correct end of the Daisy Seed diagram. Minimal change: shape only, no label required.

**DoD:** AC-30 passes. USB port shape visible at correct end of the diagram.

---

### T19-6 — Investigate and resolve xruns counter duplication in Scope view

Investigate whether the "xruns" display in the Scope view header and the "Emulator" section represent the same metric or different metrics:
- Read the C2 implementation to identify the source of each counter
- If the same metric: remove one; keep the one in the more visible location
- If different metrics: rename both for clarity (e.g. "audio xruns", "IPC xruns")
- Write FR-SC-2 acceptance criteria after investigation

**DoD:** Exactly one xruns counter visible per metric. FR-SC-2 AC is written and the implementation satisfies it.
