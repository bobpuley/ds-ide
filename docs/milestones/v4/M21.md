# M21 — VS Code Run Command Integration

**Target version:** 0.4.2
**Status:** released
**Closes:** AC-32, AC-33
**Decisions:** D20 (DebugConfigurationProvider for `ds-ide` type)

---

## Goal

Hook F5 (Start Debugging) and Ctrl+F5 (Start Without Debugging) into ds-ide via a
`DebugConfigurationProvider`. The developer presses F5 to get the full build→deploy→debug
cycle in one keystroke, without manually chaining commands.

---

## Tasks

### T21-1 — Register `DebugConfigurationProvider` for `ds-ide` debug type ✅

- Declare `debuggers` contribution point in `package.json` for type `ds-ide`.
- Register `DebugConfigurationProvider` in `C1.activate()`.
- Implement `provideDebugConfigurations()` — returns the default `launch.json` snippet so VS
  Code offers it when the developer adds a debug config.
- Implement `resolveDebugConfiguration(folder, config, token)`:
  - If `config.noDebug` is `false` (F5): stop running emulator → build → deploy → attach lldb-dap (C6).
  - If `config.noDebug` is `true` (Ctrl+F5): stop → build → deploy, no lldb.
  - On build failure: surface error in Output panel; abort (do not deploy or attach).
- Default `launch.json` snippet:
  ```json
  {
    "type": "ds-ide",
    "request": "launch",
    "name": "DS-IDE: Build, Deploy & Debug"
  }
  ```

**DoD:**
- F5 with a `ds-ide` config: emulator stops (if running), build runs, deploy runs, lldb attaches, Debug toolbar visible.
- F5 with a syntax error in source: Output panel shows error; deploy does not run; no Debug session started.
- Ctrl+F5: same stop→build→deploy; no Debug toolbar; emulator runs freely.
- No regression to existing palette commands (FR-CM-1, FR-CM-2).

---

## Acceptance criteria (verify before close)

- **AC-32** — F5 Start Debugging: with a `ds-ide` launch configuration in `launch.json` and an
  effect source open, press F5. Verify: (a) if the emulator was already running, it is stopped
  first; (b) the build runs; (c) the deploy runs; (d) lldb-dap attaches and the Debug toolbar
  appears. Repeat with a syntax error in the source: verify the deploy does not run and an error
  appears in the Output panel. *(FR-CM-3)*
- **AC-33** — Ctrl+F5 Start Without Debugging: press Ctrl+F5 with the `ds-ide` config active.
  Verify: (a) if the emulator was running, it is stopped; (b) build runs; (c) deploy runs;
  (d) emulator is running but no Debug toolbar appears (lldb not attached). *(FR-CM-4)*

---

## Notes

- The build and deploy steps reuse the internal functions already backing FR-CM-1 (`Build & Deploy to Emulator`). No new IPC messages to the emulator runtime.
- The lldb attach step reuses C6 (lldb-dap) already shipping in v2+.
- `retainContextWhenHidden` is not relevant here — this is a C1 provider, not a webview.
