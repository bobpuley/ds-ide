Reading this mockup

  • AUDIO = stopped: status shows a red ■, Freeze and 1× Single are disabled and reset (as shipped).
  • AUDIO = not deployed: only the header, events bar, getting-started steps and emulator bar are visible.
  • Trigger ≠ Free: a dotted level line and a pointer triangle appear on the amplitude axis — drag the pointer. With no crossing the last window is held and "no trigger — waiting…" is drawn.
  • Freeze: the button turns into "Resume"; "FROZEN" is drawn on the canvas, left of the gain label. Hover for the cursor read-out (top right).
  • Time = 0.5 / 1 ms/div in Free-run shows the amber "low resolution" note; a trigger switches to the emulator's full-rate capture.
  • SOURCE = clipping latches the CLIP chips, adds "⚠ CLIP" to the strip and an entry to the history (click "history").

Resolved from the original proposal

  1. Capture length: emulator-side full-rate capture on trigger (FR-SCI-14d), webview history otherwise.
  2. Trigger runs in the webview; only single-shot / fine time bases ask the emulator.
  3. Spectrum stays below the scope.
  4. Meters stay as a 132 px column.
  5. Export: PNG and CSV only (no WAV).
  6. Event history stays inside the Scope.
