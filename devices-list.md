# Devices List

| Peripheral                      | Features                                                                                                       | Electrical Specifications                                                                                                                                             |
|---------------------------------|----------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Potentiometer**               | Analog control of parameters (volume, tone, etc.). Works as a voltage divider.                                 | Voltage: 0V to 3.3V (ADC input range). Resistance: Common 10kΩ. Current: Total load of potentiometers on the 3.3V rail must be considered, as it has a 150mA limit.   |
| **Push Button / Footswitch**    | Digital input to activate/deactivate functions, change presets, etc. Footswitches are common in guitar pedals. | Voltage: 0V or 3.3V (logic levels). Pull‑up: Internal or external pull‑up resistors recommended.                                                                      |
| **Toggle Switch**               | Digital input to select modes (e.g., ON‑OFF‑ON).                                                               | Voltage: 0V or 3.3V (logic levels).                                                                                                                                   |
| **LED**                         | Digital output for visual feedback (status, bypass, etc.). Can be used with PWM for dimming.                   | Voltage: 3.3V (GPIO output voltage). Current: Requires a series current‑limiting resistor (typically 220Ω – 1kΩ) to not exceed the GPIO maximum current (about 20mA). |
| **Rotary Encoder**              | Digital input for precision control and menu navigation. Often includes a built‑in push button.                | Voltage: 0V or 3.3V (logic levels for A, B signals and button).                                                                                                       |
| **OLED Display**                | Output for graphical user interface, displaying parameters and presets. Commonly based on SSD1306 chip.        | Power: 3.3V or 5V (modules usually have onboard regulator). Logic: 3.3V. Interfaces: I2C or SPI.                                                                      |
| **Audio Jack (Input/Output)**   | Input and output of audio signal. Daisy Seed has a built‑in stereo line‑level audio codec.                     | Input Impedance: 30 kΩ (typical). Maximum Input Level: 3.6 V peak‑to‑peak (Vpp). Output Level: 1 Vrms at 0dBFS.                                                       |
| **MIDI (TRS)**                  | Serial communication for control from/to other MIDI devices. Often implemented via UART.                       | Voltage: 3.3V (UART logic levels). Standard: Requires an optoisolator for MIDI input per standard.                                                                    |
| **MicroSD Card**                | Mass storage for audio samples, presets, firmware, etc.                                                        | Power: 3.3V. Interface: SPI.                                                                                                                                          |
| **CV (Control Voltage) In/Out** | Inputs/Outputs for controlling Eurorack modular synthesizers.                                                  | Input Range: Commonly –5V to +5V.                                                                                                                                     |
